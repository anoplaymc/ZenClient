ZenClient 1.0 — мод-меню для Granny Legacy
==========================================

ЗАПУСК
------
В папке игры лежат:
  ZenClient.exe   — лаунчер с окном: «Запустить ZenClient» или «Ванильная игра»
  ZenClient.bat   — просто открывает ZenClient.exe
  ZenClient\      — сам клиент (ZenClient.dll, шрифты, настройки)
  Без окна: ZenClient.exe --zen (сразу с модом) или --vanilla (оригинал).

Steam / Proton (Linux):
  1. Steam → Библиотека → правой кнопкой по "Granny Legacy" → Свойства.
  2. В поле "Цель" (Target) замените "Granny Legacy.exe" на "ZenClient.exe"
     (кавычки оставьте, путь тот же). Папку запуска не меняйте.
  3. Совместимость: Proton (у вас уже стоит Proton Experimental).
  При запуске из Steam откроется лаунчер; выберите режим. Пока идёт игра,
  лаунчер скрыт и закрывается вместе с ней.

Windows: просто запустите ZenClient.exe или ZenClient.bat.

ПРИ ЗАПУСКЕ С ZENCLIENT
----------------------
  Стартовые заставки Unity (логотипы) пропускаются, игра открывается сразу.
  Поверх игры показывается дисклеймер (неофициальная сборка; оригинальный
  разработчик — DVLoper, сборку создал — Zenvyd) с кнопкой OK. Он появляется
  при каждом запуске с ZenClient и не отключается. Ванильный запуск не меняется.

УПРАВЛЕНИЕ
----------
  Правый Shift — открыть / закрыть меню (клавиша меняется во вкладке «Клиент»;
  Escape тоже закрывает).
  Кастомный интерфейс главного меню: Esc или кнопка «← Назад» — на экран назад.
  Полёт / Noclip: WASD — движение, Пробел — вверх, Ctrl — вниз, левый Shift — быстрее.
  Пока меню открыто, персонаж стоит на месте, а клики не уходят в игру.

ВОЗМОЖНОСТИ
-----------
  Визуал     — Full Bright: светло везде и на любой сложности (убирает
               туман-тьму Hard…Hollow и запечённые тени, яркость настраивается);
               хитбоксы NPC и предметов сквозь стены (+ подписи и расстояние).
               Вид: 3D-коробка / 2D-рамка / уголки, цвет NPC и предметов,
               толщина, заливка, линии к объектам, размер подписей, дальность.
  Игрок      — God Mode, невидимость для Гренни и Деда, заморозка врагов,
               полёт, noclip, ускорение (множитель настраивается),
               свой угол обзора (FOV), скорость времени игры,
               быстрый старт: без экрана "DAY N" и пробуждения в кровати при
               загрузке / Restart Run (опционально и для нового дня после
               поимки) и без 3.5-секундного экрана загрузки из меню.
  Ресурсы    — монеты Granny Coin: поле + "Выдать" задаёт баланс (можно и 0),
               быстрые кнопки +100…+100 000 добавляют,
               "Открыть все предметы": все 50 скинов и все покупки магазина.
               При выключении всё возвращается как было (копия в unlock_backup.ini).
  Интерфейс  — кастомный интерфейс главного меню; все кнопки и настройки игры
               остаются доступны. Game Jolt открывается в оригинальном виде,
               после закрытия кастомный интерфейс возвращается сам.
               Гибкая настройка (вкладка «Интерфейс»):
                 Готовые стили: Стандарт, Компакт, По центру, Карточка, Консоль, Плитки.
                 Макет    — слева / справа / по центру / плавающая карточка, ширина,
                            размер, сдвиг, сетка 1–4 колонки.
                 Фон      — градиент / сплошной / стекло / нет, цвет и прозрачность
                            панели, затемнение сцены, свечение, свой акцент.
                 Шапка    — свои тексты заголовка, размер, выравнивание, монеты,
                            кнопка «Назад», подсказка.
                 Кнопки   — 6 стилей, высота, отступы, скругление, текст по центру,
                            стрелки, полоска; главная кнопка («Играть»): место,
                            стиль (заливка/градиент/контур/неон), высота, пульсация.
                 Экраны   — вложенные экраны (после «Играть» и т.п.) списком,
                            во всплывашке, шторкой снизу или панелью сбоку; анимация
                            всплывашки (масштаб/снизу/пружина/плавно/сбоку), ширина,
                            скругление, затемнение; «Дополнительно» — настройки рядом
                            с «Играть» прячутся за кнопку-шестерёнку во всплывашку.
                 Анимация — тип и скорость переходов, каскадное появление кнопок.
                 Правила  — список правил редактора с удалением.
               Режим редактора: нажмите на любой элемент меню игры — его можно
               скрыть, переименовать, выделить, растянуть, поднять/опустить,
               закрепить внизу или убрать во всплывашку «Дополнительно»; кнопка
               «Этот экран» задаёт вид (список/всплывашка/шторка/сбоку) и заголовок
               для конкретного экрана. Правила сохраняются в config.ini (el.* / pg.*).
  Тема       — акцентный цвет (8 пресетов + свой), прозрачность, анимации;
               окно меню: масштаб всего интерфейса, ширина, высота, боковая
               панель, скругление, цвет фона, затемнение, анимация открытия.
  Клиент     — клавиша меню (Правый Shift, Insert, Home, End, Delete, F1, F2,
               F5, F12); водяной знак: 6 положений, 3 стиля, название/свой
               текст, FPS, время, монеты, счётчик дней (День N / 5),
               статус, размер, прозрачность;
               уведомления: вкл/выкл, угол экрана, длительность.

  Конфиги    — несколько наборов настроек (ZenClient\configs\<название>.json):
               сохранить текущие как новый, перезаписать, загрузить,
               переименовать, удалить; импорт/экспорт JSON через окно выбора
               файла или буфер обмена; «Открыть папку конфигов»; полный сброс.
               В JSON входят все параметры клиента и правила редактора меню.
               Файл можно править вручную: отсутствующие ключи получают
               стандартные значения, значения вне диапазона исправляются.

Настройки сохраняются автоматически в ZenClient\config.ini.
Если что-то пошло не так — лог последнего запуска: ZenClient\zen.log.
